# 여명 마을 - 세라피나 (AI RPG NPC)

OpenAI API를 사용해 실시간으로 대화하는 RPG 오프닝 NPC 웹 데모입니다. 정해진 질문-답변 세트가 아니라 매 질문을 OpenAI 모델에 실시간으로 전달해 답하며, 게임 세계관과 무관한 질문에는 캐릭터를 유지한 채 "그 부분에서는 답변 할 정도의 지식이 없네"류의 말로 자연스럽게 선을 긋습니다.

## 구성

- `server.js` — 정적 프론트엔드 서빙 + `/api/chat`에서 OpenAI Chat Completions API를 호출하는 백엔드. 세계관/캐릭터 시스템 프롬프트는 이 파일에 있습니다.
- `public/` — 프론트엔드 (배경 이미지 + 좌상단 이름표 + 하단 대화창).
- `public/assets/` — 채팅으로 보내주신 두 이미지를 넣는 폴더 (자세한 내용은 해당 폴더의 README 참고).

## 실행 방법

1. 의존성 설치
   ```bash
   npm install
   ```
2. 환경변수 설정
   ```bash
   cp .env.example .env
   # .env 파일을 열어 OPENAI_API_KEY 값을 본인의 OpenAI API 키로 채워주세요.
   ```
3. 이미지 넣기 — `public/assets/scene-background.jpg`, `public/assets/npc-nameplate.png` 두 파일을 채팅으로 받은 이미지 그대로 넣어주세요. (없어도 실행은 되며, 대체 화면이 표시됩니다.)
4. 서버 실행
   ```bash
   npm start
   ```
5. 브라우저에서 `http://localhost:3000` 접속

## 세계관 요약

- **왕국**: 아우렐리아 왕국. 30년 전 "잿빛 전쟁"에서 그림자 군단을 물리치고 불사조를 재건의 상징으로 삼았습니다.
- **마을**: 여명 마을(Dawn's Reach). 광장, 대장간, 길드 홀, 여관이 있는 교역 마을이며 플레이어는 방금 성문을 지나 이 광장에 도착한 신참 모험가입니다.
- **NPC**: 세라피나 — 불꽃 기사단 소속 여명 마을 경비대장. 반말 위주의 담백하고 단호한 말투를 씁니다.
- **최근 사건**: 마을 북쪽 어둠숲에서 그림자 군단 잔당으로 추정되는 무리가 다시 나타나 마을이 경계 태세에 있습니다.

전체 설정은 `server.js`의 `SYSTEM_PROMPT`에 정의되어 있으며, 여기서 세계관/성격/말투/답변 원칙을 자유롭게 조정할 수 있습니다.

## 동작 방식

- 프론트엔드는 대화 기록(history)을 배열로 들고 있다가 사용자가 메시지를 보낼 때마다 전체 기록을 `/api/chat`에 전송합니다.
- 서버는 요청마다 세계관 시스템 프롬프트를 맨 앞에 붙여 OpenAI Chat Completions API를 호출하고, 응답을 그대로 돌려줍니다. (API 키는 서버에만 있고 브라우저로 노출되지 않습니다.)
- "여긴 어디야?" / "여긴 뭐야?"처럼 표현이 달라도 같은 의도의 질문이면 모델이 의도를 파악해 답하도록 시스템 프롬프트에 명시했습니다. 고정된 Q&A 매칭이 아니라 매번 실시간으로 생성됩니다.
- 게임 세계와 무관한 질문(현실 상식, 코딩, AI 여부 질문 등)에는 캐릭터를 유지한 채 완곡하게 거절하고 다시 게임 맥락으로 대화를 유도하도록 지시되어 있습니다.
- 답변을 기다리는 동안 "생각 중" 타이핑 인디케이터가 표시되어, 화면 밖에 실제로 응답하는 상대가 있다는 느낌을 주도록 했습니다.
