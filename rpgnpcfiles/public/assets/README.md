# 이미지 에셋

이 폴더에 아래 두 파일을 넣어주세요. 채팅으로 보내주신 이미지 그대로 사용하도록 코드가 이미 연결되어 있습니다 (별도의 배경/대화창 디자인을 새로 만들지 않았습니다).

| 파일명 | 용도 | 원본 |
| --- | --- | --- |
| `scene-background.jpg` | 화면 전체를 채우는 배경이자 크게 보이는 NPC(세라피나) 이미지 | 광장에 서 있는 세라피나 풀샷 |
| `npc-nameplate.png` | 화면 좌상단에 떠 있는 초상화 + 이름표 | "세라피나 (Seraphina)" 이름표 이미지 |

파일이 아직 없어도 앱은 정상적으로 실행됩니다 — 배경은 그라데이션으로, 이름표는 숨김 처리되는 대체(fallback) 화면이 자동으로 표시됩니다. 두 파일을 이 경로에 그대로 넣기만 하면 자동으로 반영됩니다(코드 수정 불필요).

확장자가 다른 파일을 쓰고 싶다면 `public/index.html`의 `src` 경로만 맞춰 바꿔주면 됩니다.
